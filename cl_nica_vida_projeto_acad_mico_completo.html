Introdução ao Projeto

O avanço da tecnologia na área da saúde tem exigido soluções integradas que otimizem o atendimento, garantam a consistência dos dados do paciente e aumentem a eficiência operacional de clínicas e hospitais. O projeto Clínica Vida+ foi concebido como uma resposta acadêmica prática e abrangente a esses desafios.

Através da junção de fundamentos teóricos de Computação (gerenciamento ágil, estruturas de dados FIFO, circuitos e tabelas de decisão lógica proposicional e diagramação UML), o sistema simula o ciclo completo de desenvolvimento de software em saúde.

Objetivos Estratégicos

  • Gestão de Tarefas: Estruturar o planejamento de desenvolvimento do sistema em Sprints utilizando visualização Kanban.
  • Construção de Scripts: Desenvolver um módulo Python com manipulação de listas e dicionários para dados cadastrais e estatísticos.
  • Modelagem Lógica: Validar regras de negócio para liberação de consultas normais e de emergência via lógica proposicional.
  • Filas de Atendimento: Implementar o conceito de fila FIFO para gestão justa de ordem de chamada de pacientes.
  • Engenharia UML: Representar os limites do sistema e papéis operacionais (Secretária e Médico) em Diagramas de Casos de Uso.

def exibir_menu():
    print("\n" + "="*40)
    print("      CLÍNICA VIDA+ - GESTÃO DE PACIENTES")
    print("="*40)
    print("1. Cadastrar paciente")
    print("2. Ver estatísticas")
    print("3. Buscar paciente pelo nome")
    print("4. Listar todos os pacientes")
    print("5. Sair")
    print("="*40)

def cadastrar_paciente(pacientes):
    print("\n--- CADASTRO DE PACIENTE ---")
    nome = input("Nome completo: ").strip()
    if not nome:
        print("Erro: O nome não pode ser vazio!")
        return

    try:
        idade = int(input("Idade (anos): "))
        if idade < 0 or idade > 130:
            print("Erro: Idade inválida!")
            return
    except ValueError:
        print("Erro: A idade deve ser um número inteiro!")
        return

    telefone = input("Telefone de contato: ").strip()
    if not telefone:
        print("Erro: Telefone não pode ser vazio!")
        return

    paciente = {
        "nome": nome,
        "idade": idade,
        "telefone": telefone
    }
    pacientes.append(paciente)
    print(f"Éxito: Paciente '{nome}' cadastrado com sucesso!")

def ver_estatisticas(pacientes):
    print("\n--- ESTATÍSTICAS DA CLÍNICA ---")
    if not pacientes:
        print("Aviso: Nenhum paciente cadastrado no sistema.")
        return

    total = len(pacientes)
    soma_idades = sum(p["idade"] for p in pacientes)
    media_idade = soma_idades / total

    mais_novo = min(pacientes, key=lambda p: p["idade"])
    mais_velho = max(pacientes, key=lambda p: p["idade"])

    print(f"Total de pacientes cadastrados: {total}")
    print(f"Idade média dos pacientes: {media_idade:.1f} anos")
    print(f"Paciente mais novo: {mais_novo['nome']} ({mais_novo['idade']} anos)")
    print(f"Paciente mais velho: {mais_velho['nome']} ({mais_velho['idade']} anos)")

def buscar_paciente(pacientes):
    print("\n--- BUSCAR PACIENTE ---")
    if not pacientes:
        print("Aviso: Nenhum paciente cadastrado no sistema.")
        return

    termo = input("Digite o nome para buscar: ").strip().lower()
    encontrados = [p for p in pacientes if termo in p["nome"].lower()]

    if encontrados:
        for p in encontrados:
            print(f"-> Nome: {p['nome']} | Idade: {p['idade']} | Tel: {p['telefone']}")
    else:
        print(f"Nenhum paciente encontrado com termo '{termo}'.")

def listar_pacientes(pacientes):
    print("\n--- LISTA DE PACIENTES ---")
    if not pacientes:
        print("Aviso: Nenhum paciente cadastrado.")
        return

    for idx, p in enumerate(pacientes, 1):
        print(f"{idx}. {p['nome']} | Idade: {p['idade']} | Tel: {p['telefone']}")

def main():
    pacientes = [
        {"nome": "Ana Maria Silva", "idade": 28, "telefone": "(11) 98765-4321"},
        {"nome": "Carlos Rocha", "idade": 64, "telefone": "(11) 97123-8899"},
        {"nome": "Beatriz Mendonça", "idade": 12, "telefone": "(11) 95544-3322"}
    ]

    while True:
        exibir_menu()
        opcao = input("Escolha uma opção (1-5): ").strip()
        if opcao == "1": cadastrar_paciente(pacientes)
        elif opcao == "2": ver_estatisticas(pacientes)
        elif opcao == "3": buscar_paciente(pacientes)
        elif opcao == "4": listar_pacientes(pacientes)
        elif opcao == "5": print("\nEncerrando sistema... Até logo!"); break
        else: print("Opção inválida!")

if __name__ == "__main__":
    main()

Passo 03 • Lógica Proposicional & Circuitos de Decisão

Validação Logica de Atendimento

Análise proposicional para liberação de consultas normais e atendimentos de emergência.

Variável A

Tem agendamento prévio

Variável B

Documentos válidos

Variável C

Médico disponível

Variável D

Pagamentos em dia

Modalidade 1 3 / 16 Liberados

Consulta Normal

(A ∧ B ∧ C) ∨ (B ∧ C ∧ D)

Exigência: O atendimento normal exige documentos válidos e médico disponível, além de agendamento prévio OU pagamentos em dia.

Modalidade 2 6 / 16 Liberados

Atendimento de Emergência

C ∧ (B ∨ D)

Exigência: Em emergência, necessita impreterivelmente de médico disponível E (documentos válidos OU pagamentos regulares).

Estudo de Caso de Teste Solicitado: (A=F, B=V, C=V, D=F)

Avaliação Consulta Normal: (F ∧ V ∧ V) ∨ (V ∧ V ∧ F) ⇒ (F) ∨ (F) ⇒ FALSO (Bloqueado)

Justificativa: Como o paciente não tem agendamento (A=F) nem está com pagamento em dia (D=F), nenhuma das duas condições disjuntivas é satisfeita.

Avaliação Emergência: V ∧ (V ∨ F) ⇒ V ∧ (V) ⇒ VERDADEIRO (Liberado)

Justificativa: O médico está disponível (C=V) e os documentos estão válidos (B=V), permitindo a liberação do atendimento emergencial.

Simulador Interativo em Tempo Real:

Consulta Normal: BLOQUEADO (F)
Emergência: LIBERADO (V)

Tabelas-Verdade Completas (16 Combinações cada)

Linha A (Agend.) B (Doc.) C (Médico) D (Pag.) Consulta Normal: (A∧B∧C) ∨ (B∧C∧D) Emergência: C ∧ (B∨D)

Conceito Teórico FIFO:

A estrutura de Fila FIFO garante justiça absoluta no atendimento de saúde: o primeiro paciente a realizar o cadastro de chegada é estritamente o primeiro a ser chamado pelo médico. A complexidade assintótica para inserção (enqueue) e remoção (dequeue) é de O(1).

Considerações Finais & Conclusão

O desenvolvimento do projeto Clínica Vida+ permitiu integrar de forma pragmática e multidisciplinar os conceitos cruciais da Ciência da Computação aplicados à gestão de saúde. A adoção da metodologia ágil Kanban possibilitou a visibilidade completa do fluxo de entregas, otimizando o ciclo de desenvolvimento através de Sprints bem delimitadas.

A implementação do script em Python demonstrou a eficiência do uso de estruturas de dados fundamentais (listas e dicionários) para manipulação rápida em memória de registros cadastrais e cálculos estatísticos. Em paralelo, a aplicação da Fila FIFO assegurou o cumprimento rigoroso e imparcial da ordem de atendimento presencial.

Por fim, a modelagem lógica proposicional e o Diagrama de Casos de Uso UML homologaram as regras de negócio clínicas, garantindo a rastreabilidade e a segurança operacional entre os perfis de secretária e médico.
